Text to Voice

An interactive Text-to-Voice web application that converts user-entered text into speech using the browser's Speech Synthesis API.

Features
Convert text into speech
Simple text input interface
One-click Speak functionality
Empty-input validation
Clean and user-friendly design
Responsive layout
Technologies
HTML5
CSS3
JavaScript
Web Speech API
How It Works
Enter text in the text area.
Click the Speak button.
The application uses the browser's speech synthesis functionality to read the text aloud.
Project Purpose

This project was developed to practice JavaScript DOM manipulation, event handling, browser APIs, and interactive web development while creating a simple accessibility-focused application.
